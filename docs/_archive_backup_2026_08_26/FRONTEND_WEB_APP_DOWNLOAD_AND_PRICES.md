## 1) نص تحميل التطبيق

### أين

قسم «حمّل التطبيق» في الصفحة الرئيسية / الهبوط (فوق أزرار جوجل بلاي وآب ستور).

النص **ليس من الـ API** — ثابت في كود الموقع أو ملفات الترجمة (`i18n`).

### التعديل المطلوب

| | النص |
|--|------|
| **قبل** | كل ما تحبه، يصلك بابتسامة. عروض رائعة **ومنتجات طازجة** وفرحة صغيرة في كل سلة. |
| **بعد** | كل ما تحبه، يصلك بابتسامة. عروض رائعة وفرحة صغيرة في كل سلة. |

احذف عبارة **«ومنتجات طازجة»** فقط. أبقِ باقي الجملة والأزرار كما هي:

- احصل عليه من جوجل بلاي
- حمّل من آب ستور

### بحث مقترح في الريبو

```text
منتجات طازجة
يصلك بابتسامة
عروض رائعة
فرحة صغيرة في كل سلة
```

حدّث النسخة العربية والإنجليزية إن وُجدت ترجمة مقابلة (مثلاً احذف "and fresh products").

## 2) عرض الأسعار

الـ API يرجع لكل سعر حقولاً مزدوجة. **لا تحسب سعر الصرف في الفرونت** — اعرض ما يأتي من السيرفر.

### شكل الاستجابة (منتج / سلة / طلب)

```json
{
  "price": 5.01,
  "currency": "SYP",
  "currency_symbol": "ل.س",
  "price_formatted": "ل.س 5.01",
  "price_currencies": {
    "USD": {
      "amount": 0.000385,
      "currency": "USD",
      "symbol": "$",
      "formatted": "$ 0.000385"
    },
    "SYP": {
      "amount": 5.01,
      "currency": "SYP",
      "symbol": "SYP",
      "formatted": "SYP 5.01"
    }
  },
  "price_after_discount": 5.01,
  "price_after_discount_currencies": { "USD": {}, "SYP": {} }
}
```

### قواعد العرض

| الشاشة | اعرض |
|--------|------|
| قائمة منتجات / كروت | `price_formatted` أو عملة المستخدم الحالية |
| تفاصيل المنتج | السعر النهائي من `price_after_discount` (+ اختياري: السعر الأصلي مشطوب إن وُجد خصم) |
| إن احتجت الدولار والليرة معاً | `price_currencies.USD` + `price_currencies.SYP` |

```js
function formatDual(currencies) {
  if (!currencies) return '';
  const usd = currencies.USD?.formatted;
  const syp = currencies.SYP?.formatted;
  return [usd, syp].filter(Boolean).join(' / ');
}
```

عملة المستخدم تأتي من إعداداته (`GET /api/user/currency` أو ضمن البروفايل). الحقل الأساسي `price` يكون محوَّلاً لعملته؛ `*_currencies` ثابت USD+SYP للعرض الثنائي.

## 3) Checklist

- [ ] إزالة «ومنتجات طازجة» من نص تحميل التطبيق (AR + EN إن لزم)
- [ ] عدم الاعتماد على حساب صرف محلي — استخدم `*_currencies` أو `*_formatted`
- [ ] في صفحة المنتج: أظهر `price_after_discount` كسعر أساسي للشراء
- [ ] إن وُجد خصم: السعر الأصلي مشطوب + السعر بعد الخصم بارز
