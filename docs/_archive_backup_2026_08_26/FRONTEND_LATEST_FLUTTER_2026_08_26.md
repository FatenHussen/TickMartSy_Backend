## 1) منتج بدون فرع → صار للموقع تلقائياً (مهم)

### المشكلة قبل

الأدمن كان يقدر يحفظ منتج **بدون ربط فرع** (`shop_variants`).  
النتيجة في التطبيق:

- صفحة المنتج تفتح (في `shop_variants` عنصر fallback)
- بس `shop_id` و `id` = **`null`**
- زر السلة لازم يكون معطّل → المستخدم ما يقدر يشتري

### شو صار بالباك إند

عند **إنشاء / تحديث منتج من الأدمن** بدون فرع:

1. يُنشأ متغيّر افتراضي إن لزم
2. يُربَط تلقائياً بـ **فرع البائع الافتراضي** (`shops.is_default = true`)
3. إذا ما في `is_default` → أول فرع نشط لنفس البائع

```
حفظ منتج بدون فرع
        ↓
متغيّر (سعر + كمية)
        ↓
ربط تلقائي بفرع is_default
        ↓
GET /api/user/products/{id}
        ↓
shop_variants[0].id      ≠ null
shop_variants[0].shop_id ≠ null
        ↓
يُضاف للسلة بشكل طبيعي
```

### شكل الرد بعد الحفظ (الحالة الطبيعية)

```json
{
  "shop_variants": [
    {
      "id": 101,
      "variant_id": 44,
      "shop_id": 1,
      "price": 25,
      "quantity": 12,
      "sku": "SITE-001"
    }
  ]
}
```

### هل التطبيق يحتاج تعديل كود؟

**لا endpoints جديدة.** نفس:

```http
GET /api/user/products/{id}
```

| قبل (منتج بدون فرع) | بعد (بعد حفظ الأدمن) |
|---------------------|----------------------|
| `shop_id: null` | `shop_id` = فرع المنصة/البائع الافتراضي |
| `id: null` | `id` = `shop_product_variant_id` حقيقي |
| السلة معطّلة | السلة تشتغل |

**خلّوا الحماية القديمة** — لا تشيلوا فحص `null`:

```dart
bool canAddToCart(ShopVariant? v) =>
    v?.shopId != null && v?.id != null && (v?.quantity ?? 0) > 0;
```

ليش؟ لأن المنتجات **القديمة** (قبل التحديث) أو بائع **بدون أي فرع** ممكن يضلوا `shop_id = null` لحد ما الأدمن يعيد الحفظ أو يضيف فرع افتراضي.

### تدفق الشراء (ما تغيّر)

```dart
// إضافة للسلة / إنشاء طلب
{
  "shop_product_variant_id": selected.id, // لازم رقم حقيقي
  "quantity": 1
}
```

- لا ترسلوا سعراً من التطبيق
- لا تفترضوا أن كل منتج دائماً مربوط — افحصوا `canAddToCart`

### Checklist — منتج / سلة

- [ ] صفحة المنتج ما تنكسر إذا `shop_variants` فيها عنصر واحد
- [ ] `shop_id == null` أو `id == null` → عطّل السلة + رسالة واضحة (مثلاً «غير متاح حالياً»)
- [ ] بعد ربط الأدمن بالفرع الافتراضي → السلة تشتغل بدون تحديث للتطبيق
- [ ] أرسلوا فقط `shop_product_variant_id` + `quantity`

## 2) عرض السعر

| الاستخدام | الحقل |
|-----------|--------|
| كروت / قوائم | `price_after_discount_formatted` أو `price_formatted` |
| دولار + ليرة معاً | `price_currencies` / `price_after_discount_currencies` |
| السلة / الطلب | مبالغ الـ API الجاهزة — لا تسعّر محلياً |

```dart
// عرض عادي
Text(product.priceAfterDiscountFormatted ?? product.priceFormatted ?? '');

// عملتين (إن التصميم يطلب)
final dual = json['price_after_discount_currencies'];
final label = [
  dual?['USD']?['formatted'],
  dual?['SYP']?['formatted'],
].whereType<String>().join(' / ');
```

### قواعد السعر

1. لا تحسب سعر الصرف داخل التطبيق
2. للشراء اعرض السعر بعد الخصم إن وُجد
3. إضافة للسلة: أرسل ids + كمية فقط؛ السيرفر يحسب السعر

> حذف الفئات وتسعير الأدمن بالليرة = **داشبورد فقط** — التطبيق ما له شغل فيهم.
