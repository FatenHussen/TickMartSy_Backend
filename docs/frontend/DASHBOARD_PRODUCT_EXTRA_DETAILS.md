## 1) الحقول

| الحقل | مطلوب؟ | الوصف |
|-------|--------|--------|
| `category_id` | نعم | الفئة التي تتبع لها الإضافة |
| `detail_key[ar]` / `detail_key[en]` | نعم (اسم الإضافة) | اسم الإضافة بالعربي/الإنجليزي |
| `price` | نعم | سعر الإضافة (رقم ≥ 0، كسور مسموحة) |
| `detail_value[ar]` / `detail_value[en]` | لا | وصف اختياري فقط — **ليس** السعر |
| `is_active` | لا | افتراضي `true` |

**لا** تستخدموا `detail_value` كسعر. السعر حقل منفصل: `price`.

---

## 2) تسميات الواجهة

استبدلوا النصوص الحالية:

| حالياً (غلط) | المطلوب |
|--------------|---------|
| عنوان التفصيل | **اسم الإضافة** |
| قيمة التفصيل (مثال: قطن) | احذفوا أو حوّلوه لـ **وصف اختياري** |
| — | أضيفوا حقل **السعر** (`number` / `decimal`) |
| إنشاء التفصيل | **إنشاء الإضافة** |

Placeholder مقترح للاسم: `تغليف هدايا` / `Gift Wrapping` — مو `قطن` / `Cotton`.

## 3) إنشاء / تعديل

### POST `/api/admin/product-extra-details`

```json
{
  "category_id": 5,
  "detail_key": {
    "ar": "تغليف هدايا",
    "en": "Gift Wrapping"
  },
  "price": 50,
  "detail_value": {
    "ar": "تغليف فاخر مع بطاقة",
    "en": "Premium wrap with card"
  },
  "is_active": true
}
```

`detail_value` يمكن حذفه بالكامل إذا ما في وصف.

### الاستجابة (مختصر)

```json
{
  "id": 12,
  "category": { "id": 5, "name": "..." },
  "detail_key": { "ar": "تغليف هدايا", "en": "Gift Wrapping" },
  "detail_value": { "ar": "...", "en": "..." },
  "price": 50,
  "is_active": true
}
```

القائمة (`GET`) ترجع نفس الحقول بما فيها `price`.

## 4) ربط الإضافة بالمنتج

عند إنشاء/تعديل منتج، اختاروا إضافة من الـ pool:

```json
{
  "extra_details": [
    {
      "product_extra_detail_id": 12,
      "quantity": 1,
      "price": 50
    }
  ]
}
```

- إذا أرسلتم `price` على المنتج → يُستخدم هذا السعر لهذا المنتج.
- إذا **ما** أرسلتم `price` → الباك يأخذ **سعر الإضافة الافتراضي** من الـ pool (`product-extra-details.price`).

في فورم المنتج: عرض اسم الإضافة + حقل سعر (مسبقاً مملوء من سعر الـ pool، قابل للتعديل).
