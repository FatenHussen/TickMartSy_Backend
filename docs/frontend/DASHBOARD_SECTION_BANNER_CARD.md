# الداشبورد — بطاقة البنر: صورة واسم فقط

> **أرسلوا هذا الملف لفريق الداشبورد فقط.**  
> **آخر تحديث:** 25 أيلول 2026  
> Base: `/api/admin` + Admin token  
> **الباك جاهز بعد `git pull`**  
> الشاشة: `/sections/pages/details/{pageId}`  
> مسح حقول البنر: [`DASHBOARD_BANNER_CLEAR_FIELDS.md`](./DASHBOARD_BANNER_CLEAR_FIELDS.md)

بشاشات **إضافة قسم** و**بطاقات البنر داخل الصفحة** اعرضوا **الصورة والاسم فقط**.  
إذا ما في اسم، الصورة لحاله.  
لا تعرضوا الرقم ولا الرابط ولا الوصف ولا نص الزر على هالبطاقات.

جدول إدارة البانرات (`/sections/banners`) يبقى كما هو. الموقع والتطبيق يقرؤون الوصف والرابط من نفس الـ API — لا تحذفوها من الرد.

## 1) وين

| الشاشة | السلوك |
|--------|--------|
| إضافة قسم → قائمة اختيار البانرات | صورة + اسم. بدون اسم = صورة فقط |
| صفحة القسم `/sections/pages/details/{id}` → بطاقة البنر | صورة + اسم. بدون اسم = صورة فقط |
| جدول البانرات `/sections/banners` | بدون تغيير (عنوان، وصف، رابط، انتهاء) |

## 2) شو ينعرض

| يظهر | لا يظهر على البطاقة |
|------|---------------------|
| الصورة | `id` / الرقم |
| الاسم (`title`) إذا فيه نص | `link` |
| | `description` / `desc` |
| | `button_text` |
| | `expires_at` |
| | `order` |

الاسم فاضي (`null` أو `""` أو `{ ar: null, en: null }`) → لا سطر اسم، البطاقة صورة فقط. لا تخفوا البنر.

## 3) من وين الاسم والصورة

### قائمة الاختيار — `GET /api/admin/banners`

```json
{
  "id": 12,
  "title": "عرض الصيف",
  "image_url": "https://…/storage/….jpg",
  "description": "…",
  "link": "https://…",
  "expires_at": null
}
```

- الصورة = `image_url`
- الاسم = `title` (String حسب اللغة، أو `null`)
- `description` و `link` و `expires_at` موجودة بالرد — **لا ترسموها** بهالقائمة

### بطاقة داخل القسم

من عناصر القسم. الشكل:

```json
{
  "id": 4,
  "link": "https://example.com",
  "order": 0,
  "item": {
    "id": 12,
    "title": "عرض الصيف",
    "desc": "خصم",
    "button_text": "تسوق",
    "image": "https://…/storage/….jpg"
  }
}
```

- الصورة = `item.image`
- الاسم = `item.title`
- لا تعرضوا `id` ولا `link` ولا `order` ولا `item.desc` ولا `item.button_text`

إذا `title` كائن `{ ar, en }`: اعرضوا لغة الواجهة، وإذا فاضية اللغة الثانية. الاتنين فاضيين → صورة فقط.

```js
function bannerName(title) {
  if (typeof title === 'string') return title.trim();
  if (title && typeof title === 'object') {
    return (title.ar || title.en || '').trim();
  }
  return '';
}
```

## 4) غلط vs صح

**غلط**

```text
بطاقة: #12 · عرض الصيف · خصم على الإلكترونيات · https://…
```

**صح**

```text
[صورة]
عرض الصيف
```

```text
[صورة]
```

الحالة الثانية لما `title` يكون `null`.
