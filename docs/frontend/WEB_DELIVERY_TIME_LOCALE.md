> **أرسلوا هذا الملف لفريق الويب فقط.**  
> **آخر تحديث:** 29 تشرين الأول 2026  
> Base: `/api/user` + `Accept-Language: ar|en`  
> **الباك جاهز بعد `git pull`**  
> Flutter: [`FLUTTER_DELIVERY_TIME_LOCALE.md`](./FLUTTER_DELIVERY_TIME_LOCALE.md)  
> السلة ما زالت بلا هذا الحقل: [`WEB_CART_NO_DELIVERY_TIME.md`](./WEB_CART_NO_DELIVERY_TIME.md)

ما في حقل جديد ولا طلب جديد. نفس `delivery_time` على صفحة المنتج. منتجات تيك مول ما عادت ترجع «ساعة» دائماً.

الشريحة في التطبيق كانت: `Delivery time: 12-48 ساعة` والواجهة إنجليزية. السبب إن القيمة كانت عربية ثابتة. الآن الوحدة تتبع `Accept-Language`.

## 1) القاعدة

| المنتج | `Accept-Language: en` | `Accept-Language: ar` |
|--------|------------------------|------------------------|
| تيك مول | `12-48 hours` | `12-48 ساعة` |
| بائع كتب المدة بنفسه | النص كما أُدخل، بلا ترجمة | النص كما أُدخل، بلا ترجمة |
| بلا مدة | `null` | `null` |

- عنوان الشريحة («Delivery time» / «مدة التوصيل») من ترجمة الموقع.
- القيمة من `product.delivery_time` فقط. لا تضيفوا `hours` ولا `ساعة` ولا `أيام` بعد النص.
- عند تبديل اللغة أعيدوا طلب المنتج. لا تبقوا النص في الكاش عبر اللغتين.
- الشاشة الإنجليزية لازم ترسل `Accept-Language: en` على نفس الطلب الذي يجيب الاسم والوصف. هيدر ناقص يرجع لغة الافتراضي (غالباً عربي).

النص العربي فيه علامتان غير مرئيتين حول `12-48` (`U+2066` … `U+2069`) حتى يبقى المدى `12-48` وما ينقلب إلى `48-12` وما تتحرك «ساعة». لا تعملوا `trim` يمسح محارف الاتجاه، ولا تعيدوا تركيب النص من الأرقام.

## 2) الرد

```http
GET /api/user/products/{id}
Accept-Language: en
```

```json
{ "delivery_time": "12-48 hours" }
```

```http
GET /api/user/products/{id}
Accept-Language: ar
```

```json
{ "delivery_time": "12-48 ساعة" }
```

نفس السلسلة على عنصر الطلب `items[].delivery_time` إذا كنتم تعرضونه بعد إنشاء الطلب، وعلى `restaurant_meta.delivery_time_range` إذا الكرت يقرأها. اعرضوها كما رجعت.

بائع كتب «3-5 أيام» يرجع «3-5 أيام» في اللغتين. لا تترجموها في الواجهة.

## 3) العرض

```jsx
{product.delivery_time && (
  <span className="delivery-chip">
    <ClockIcon />
    <span>{t('deliveryTime')}</span>
    <span>{product.delivery_time}</span>
  </span>
)}
```

- مرة واحدة على المنتج، مو لكل متغيّر.
- لا `replace`، لا قص للأرقام، لا `dir="ltr"` على القيمة العربية. الاتجاه داخل النص جاهز.
- `null` أو `""` → لا شريحة.

## 4) لا تخلطوه مع حقول ثانية

| الحقل | وين | شو هو |
|--------|-----|--------|
| `product.delivery_time` | صفحة المنتج | نص جاهز للعرض |
| `checkout.delivery_min_hours` / `delivery_max_hours` | السلة | أرقام ساعات لأقرب توصيل. مو هالنص |
| `delivery_time` في جدولة السلة | جدولة | `HH:mm` يختاره الزبون |

السلة والدفع والمراجعة يبقون بلا `product.delivery_time`.

## 5) غلط vs صح

| غلط | صح |
|------|-----|
| تثبيت `12-48 ساعة` في الكود | عرض `product.delivery_time` |
| إنجليزي + لصق «ساعة» لأن النص القديم كان كذا | `12-48 hours` لما الهيدر `en` |
| `` `${value} ساعة` `` أو `` `${value} hours` `` | القيمة وحدها |
| تنظيف السلسلة من محارف الاتجاه | النص كما رجع من الـ JSON |
| نص عربي مخزّن بعد تحويل اللغة | إعادة جلب المنتج مع الهيدر الجديد |
| سطر مدة داخل السلة | صفحة المنتج فقط |
