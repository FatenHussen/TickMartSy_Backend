ما في حقل جديد ولا طلب جديد. نفس `delivery_time` على صفحة المنتج. منتجات تيك مول ما عادت ترجع «ساعة» دائماً.

الشريحة في الصورة كانت: `Delivery time: 12-48 ساعة` والواجهة إنجليزية. السبب إن القيمة كانت عربية ثابتة. الآن الوحدة تتبع `Accept-Language`.

## 1) القاعدة

| المنتج | `Accept-Language: en` | `Accept-Language: ar` |
|--------|------------------------|------------------------|
| تيك مول | `12-48 hours` | `12-48 ساعة` |
| بائع كتب المدة بنفسه | النص كما أُدخل، بلا ترجمة | النص كما أُدخل، بلا ترجمة |
| بلا مدة | `null` | `null` |

- عنوان الشريحة («Delivery time» / «مدة التوصيل») من ترجمة التطبيق.
- القيمة من `delivery_time` فقط. لا تضيفوا `hours` ولا `ساعة` ولا `أيام` بعد النص.
- عند تبديل اللغة أعيدوا طلب المنتج. لا تبقوا النص القديم في الموديل.
- إذا الهيدر ناقص أو غير `ar` / `en`، الباك يرجع لغة الافتراضي (غالباً عربي). الشاشة الإنجليزية لازم ترسل `Accept-Language: en` على نفس الطلب الذي يجيب الاسم والوصف.

النص العربي فيه علامتان غير مرئيتين حول `12-48` (`U+2066` … `U+2069`) حتى يبقى المدى `12-48` وما ينقلب إلى `48-12` وما تتحرك «ساعة». لا تحذفوا محارف ما بتنشوف، ولا تعيدوا تركيب النص من الأرقام.

## 2) الرد

```http
GET /api/user/products/{id}
Accept-Language: en
```

```json
{ "delivery_time": "12-48 hours" }
```

```http
GET /api/user/products/{id}
Accept-Language: ar
```

```json
{ "delivery_time": "12-48 ساعة" }
```

نفس السلسلة على عنصر الطلب `items[].delivery_time` إذا كنتم تعرضونه بعد إنشاء الطلب، وعلى `restaurant_meta.delivery_time_range` إذا الكرت يقرأها. اعرضوها كما رجعت.

بائع كتب «3-5 أيام» يرجع «3-5 أيام» في اللغتين. لا تترجموها على الجهاز.

## 3) العرض

```dart
// صفحة المنتج فقط
final value = product.deliveryTime;
if (value != null && value.isNotEmpty) {
  Row(
    children: [
      const Icon(Icons.schedule_outlined),
      Text(context.l10n.deliveryTime), // Delivery time / مدة التوصيل
      Text(value), // كما رجع من الـ API
    ],
  );
}
```

- مرة واحدة على المنتج، مو لكل متغيّر.
- `Text` ياخد السلسلة كاملة. لا `substring`، لا `replaceAll('ساعة', 'hours')`، لا `split('-')`.
- لا تفرضوا `TextDirection.ltr` على القيمة العربية. العلامات داخل النص تثبّت الأرقام.
- `null` أو `""` → أخفوا الشريحة.

## 4) لا تخلطوه مع حقول ثانية

| الحقل | وين | شو هو |
|--------|-----|--------|
| `product.deliveryTime` | صفحة المنتج | نص جاهز للعرض |
| `checkout.delivery_min_hours` / `delivery_max_hours` | السلة | أرقام ساعات لأقرب توصيل. مو هالنص |
| `delivery_time` في جدولة السلة | جدولة | `HH:mm` يختاره الزبون |

السلة والدفع والمراجعة يبقون بلا `product.deliveryTime`.

## 5) غلط vs صح

| غلط | صح |
|------|-----|
| تثبيت `12-48 ساعة` في الكود | عرض `deliveryTime` |
| إنجليزي + لصق «ساعة» لأن النص القديم كان كذا | `12-48 hours` لما الهيدر `en` |
| `'$value ساعة'` أو `'$value hours'` | القيمة وحدها |
| قلب السلسلة أو حذف المحارف المخفية | `Text(value)` كما هو |
| نص عربي مخزّن بعد ما المستخدم حوّل للإنجليزي | إعادة جلب المنتج مع اللغة الجديدة |
| رسم المدة داخل السلة | صفحة المنتج فقط |
