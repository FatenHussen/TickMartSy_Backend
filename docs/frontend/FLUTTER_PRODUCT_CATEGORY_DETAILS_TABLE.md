## 1) القاعدة

| العنصر | المطلوب |
|--------|---------|
| صف ترويسة «الاسم» / «القيمة» | ❌ احذفوه بالكامل |
| عنوان القسم «التفاصيل» | ✅ يبقى فوق الجدول |
| صفوف البيانات (`name` · `value`) | ✅ فقط |
| فاصل عمودي بين الاسم والقيمة | ✅ إلزامي — يبين كعمودين مو سطر متصل |

الـ API **لا** يرسل صف ترويسة. «الاسم» و«القيمة» من الواجهة فقط — احذفوهما.

---

## 2) الـ API

```http
GET /api/user/products/{id}
Accept-Language: ar
```

```json
{
  "category_details": [
    { "id": 1, "name": "الطول", "value": "97 cm" },
    { "id": 2, "name": "المقاس", "value": "S" }
  ]
}
```

| حقل | نوع | عرض |
|-----|-----|-----|
| `name` | string (حسب اللغة) | عمود اليمين (RTL) |
| `value` | string | عمود اليسار |

`category_details: []` → اخفوا القسم بالكامل.

## 3) العرض

```
| التفاصيل:
┌─────────────────┬──────────┐
│ الطول           │ 97 cm    │
├─────────────────┼──────────┤
│ المقاس          │ S        │
└─────────────────┴──────────┘
```

- **لا** صف أول فيه نص ثابت «الاسم» و«القيمة»
- بين العمودين: `VerticalDivider` أو border يسار/يمين للخلية — خط واضح
- كل صف: خلفية بيضاء / زوايا كما هي — المهم الفاصل العمودي

```dart
// لا DataColumn(label: Text('الاسم')) / Text('القيمة')
// لا TableRow ترويسة

Row(
  children: [
    Expanded(child: Text(detail.name)), // الطول
    Container(width: 1, color: Colors.grey.shade300), // الفاصل
    Expanded(child: Text(detail.value, textAlign: TextAlign.end)), // 97 cm
  ],
);
```

## 4) غلط vs صح

**غلط**

```dart
DataTable(
  columns: const [
    DataColumn(label: Text('الاسم')),
    DataColumn(label: Text('القيمة')),
  ],
  rows: details.map(...).toList(),
);
// أو صفوف بلا Divider → يبدو سطر متصل
```

**صح**

```dart
// عنوان القسم فقط: «التفاصيل»
// ثم صفوف name | value مع VerticalDivider
// بدون أي ترويسة
```

## 5) Checklist

- [ ] لا يظهر سطر «الاسم» / «القيمة»
- [ ] عنوان «التفاصيل» يبقى
- [ ] فاصل عمودي واضح بين الاسم والقيمة في كل صف
- [ ] القائمة من `category_details` فقط — لا صفوف وهمية
- [ ] مصفوفة فارغة → إخفاء القسم

**الباك جاهز — التطبيق يتبع هذا الملف.**
