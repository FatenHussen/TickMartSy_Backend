# الداشبورد — كمية المنتج: توست «موجبة» (باگ validation)

> **الجمهور:** فريق الداشبورد  
> **تاريخ:** 5 أيلول 2026 — **محدَّث 8 أيلول 2026**  
> **الباك:** جاهز — `quantity` و `variants.*.quantity` كلاهما `nullable|min:0`  
> **لا required** على السعر / التكلفة / الكمية / SKU / الوزن

> **8 أيلول:** قرار حذف الكمية من تاب المعلومات **ملغى**.  
> الكمية + السعر + الخصم + الباركود + SKU **يظهرون في تاب المعلومات دائماً**، ونفس الحقول على كارد المتغيّر.  
> الدليل المعتمد: [`DASHBOARD_PRODUCT_PRICING_FIELDS.md`](./DASHBOARD_PRODUCT_PRICING_FIELDS.md)

---

## 1) القرار (قديم — لا تتبعوه)

~~حقل كمية المنتج يُحذف من تاب المعلومات الأساسية.~~ **ملغى 8 أيلول.**

أبقوا الكمية في تاب المعلومات. الكمية على كارد المتغيّر تبقى `variants[].quantity` — **اختياري**.

فارغ = لا ترسلوا الحقل. معبّى على المنتج = أرسلوا `quantity`. معبّى على الكارد = أرسلوا `variants[i][quantity]`.

---

## 2) باگ التوست «يجب أن تكون الكمية موجبة»

كان Zod يطلب `quantity` إلزامي (`invalid_type` إذا `undefined`).  
الحل: الحقل موجود واختياري — `.optional()` على كمية المنتج **و** كمية المتغيّر. لا توست إذا فاضي.

---

## 3) حقول من الواجهة المرجعية — كلها اختيارية

| الحقل | أين | إلزامي؟ | ملاحظة |
|--------|------|---------|--------|
| رقم المنتج | المعلومات الأساسية | ❌ | `product_number` |
| الاسم عربي / إنجليزي | المعلومات الأساسية | الاسم مطلوب من الباك لإنشاء المنتج | بدون نجمة `*` على باقي الحقول |
| الموديل · SKU · باركود | المعلومات الأساسية | ❌ | |
| مكان التواجد / لمن | المعلومات الأساسية | ❌ | `sale_channel` / `vendor_scope` |
| بلد المنشأ / بلد المبيع | المعلومات الأساسية | ❌ | |
| الخصم · الضمان | المعلومات الأساسية | ❌ | |
| سعر $ · سعر ل.س · كمية | المعلومات الأساسية | ❌ | **دائماً ظاهر** — انظر [`DASHBOARD_PRODUCT_PRICING_FIELDS.md`](./DASHBOARD_PRODUCT_PRICING_FIELDS.md) |
| ظاهر في المتجر | المعلومات الأساسية | ❌ | `is_visible` افتراضي ظاهر |
| الصورة الرئيسية + الصور | تاب الصور / قسم الصور | ❌ | |
| SEO | تاب السيو | ❌ | عنوان · وصف · كلمات · صورة |
| أيقونات · بادج أعلى/أسفل | تاب التفاصيل / extras | ❌ | |
| SKU · سعر · تكلفة · كمية المتغيّر | تاب المتغيّرات | ❌ | الكمية = `variants[].quantity` |
| الوزن | — | — | **غير موجود على الباك** `product_variants` — لا تعرضوه ولا ترسلوه |

---

## 4) Payload

```text
# ✅ كمية على المنتج (تاب المعلومات) و/أو المتغيّر
quantity=50
variants[0][quantity]=5

# ✅ فارغ — لا ترسلوا الحقل
```

فارغ = لا ترسلوا الحقل.

---

## 5) Checklist

- [ ] `quantity` موجود في تاب المعلومات — اختياري `.optional()`
- [ ] `variants[].quantity` اختياري — `.optional()` + لا `required`
- [ ] لا `formData.append('quantity')` إلا إذا رقم صالح
- [ ] رقم المنتج `product_number` اختياري
- [ ] لا نجمة `*` على سعر / كمية / تكلفة / وزن / SKU
- [ ] لا توست «الكمية موجبة» إذا الحقل فاضي
- [ ] التخطيط الكامل: [`DASHBOARD_PRODUCT_PRICING_FIELDS.md`](./DASHBOARD_PRODUCT_PRICING_FIELDS.md)
