# الداشبورد — كمية المنتج: حُذفت من المعلومات الأساسية

> **الجمهور:** فريق الداشبورد  
> **تاريخ:** 5 أيلول 2026  
> **الباك:** جاهز — `quantity` و `variants.*.quantity` كلاهما `nullable|min:0`  
> **لا required** على السعر / التكلفة / الكمية / SKU / الوزن

---

## 1) القرار

حقل **كمية المنتج** (`quantity` على مستوى المنتج) **يُحذف من تاب المعلومات الأساسية** — لا يُخفى، يُزال.

الكمية تُدخل فقط على **كارد المتغيّر**: `variants[].quantity` — **اختياري**.

لا ترسلوا `quantity` مع `POST/PUT /products` إذا ما في قيمة على المنتج. أرسلوا `variants[i][quantity]` فقط عند تعبئة الكارد.

---

## 2) باگ التوست «يجب أن تكون الكمية موجبة»

كان Zod يطلب `quantity` المنتج المخفي (`invalid_type` و القيمة `undefined`).  
الحل: لا حقل منتج، ولا validation إلزامي، والكمية على المتغيّر `.optional()`.

---

## 3) حقول من الواجهة المرجعية — كلها اختيارية

| الحقل | أين | إلزامي؟ | ملاحظة |
|--------|------|---------|--------|
| رقم المنتج | المعلومات الأساسية | ❌ | `product_number` |
| الاسم عربي / إنجليزي | المعلومات الأساسية | الاسم مطلوب من الباك لإنشاء المنتج | بدون نجمة `*` على باقي الحقول |
| الموديل · SKU · باركود | المعلومات الأساسية | ❌ | |
| مكان التواجد / لمن | المعلومات الأساسية | ❌ | `sale_channel` / `vendor_scope` |
| بلد المنشأ / بلد المبيع | المعلومات الأساسية | ❌ | |
| الخصم · الضمان | المعلومات الأساسية | ❌ | |
| ظاهر في المتجر | المعلومات الأساسية | ❌ | `is_visible` افتراضي ظاهر |
| الصورة الرئيسية + الصور | تاب الصور / قسم الصور | ❌ | |
| SEO | تاب السيو | ❌ | عنوان · وصف · كلمات · صورة |
| أيقونات · بادج أعلى/أسفل | تاب التفاصيل / extras | ❌ | |
| SKU · سعر · تكلفة · كمية المتغيّر | تاب المتغيّرات | ❌ | الكمية = `variants[].quantity` |
| الوزن | — | — | **غير موجود على الباك** `product_variants` — لا تعرضوه ولا ترسلوه |

---

## 4) Payload

```text
# ✅ كمية على المتغيّر فقط
variants[0][quantity]=5

# ❌ لا
quantity=5
```

فارغ = لا ترسلوا الحقل.

---

## 5) Checklist

- [ ] لا input `name="quantity"` في تاب المعلومات الأساسية
- [ ] لا `usesVariantPricing` لإخفاء كمية المنتج — الحقل غير موجود
- [ ] `variants[].quantity` اختياري — `.optional()` + لا `required`
- [ ] لا `formData.append('quantity')` إلا إذا رقم صالح (يفضّل عدم الإرسال)
- [ ] رقم المنتج `product_number` اختياري
- [ ] لا نجمة `*` على سعر / كمية / تكلفة / وزن / SKU
- [ ] لا توست «الكمية موجبة» لأن المنتج فاضي

**الباك جاهز — الداشبورد يتبع هذا الملف.**
