## 1) القاعدة

| العنصر | المطلوب |
|--------|---------|
| صف ترويسة «الاسم» / «القيمة» | ❌ احذفوه بالكامل |
| عنوان القسم «التفاصيل» | ✅ يبقى فوق الجدول |
| صفوف البيانات (`name` · `value`) | ✅ فقط |
| فاصل عمودي بين الاسم والقيمة | ✅ إلزامي — يبين كعمودين مو سطر متصل |

الـ API **لا** يرسل صف ترويسة. «الاسم» و«القيمة» من الواجهة فقط — احذفوهما.

---

## 2) الـ API

```http
GET /api/user/products/{id}
Accept-Language: ar
```

```json
{
  "category_details": [
    { "id": 1, "name": "الطول", "value": "97 cm" },
    { "id": 2, "name": "المقاس", "value": "S" }
  ]
}
```

`category_details: []` → اخفوا القسم بالكامل.

## 3) العرض

```
| التفاصيل:
┌─────────────────┬──────────┐
│ الطول           │ 97 cm    │
├─────────────────┼──────────┤
│ المقاس          │ S        │
└─────────────────┴──────────┘
```

```jsx
{/* بدون <th>الاسم</th> / <th>القيمة</th> */}
<section>
  <h3>التفاصيل</h3>
  <ul>
    {categoryDetails.map((d) => (
      <li key={d.id} className="grid grid-cols-2 border-b">
        <span className="border-l border-slate-200 pe-3">{d.name}</span>
        <span className="ps-3 text-start">{d.value}</span>
      </li>
    ))}
  </ul>
</section>
```

الفاصل = `border` بين العمودين (أو عمود وسط رفيع) — مش مسافة فقط.

---

## 4) غلط vs صح

**غلط**

```jsx
<thead>
  <tr><th>الاسم</th><th>القيمة</th></tr>
</thead>
{/* أو صفوف بلا border بين العمودين */}
```

**صح**

```jsx
{/* عنوان القسم فقط + صفوف name | value مع فاصل عمودي */}
```

## 5) Checklist

- [ ] لا يظهر سطر «الاسم» / «القيمة»
- [ ] عنوان «التفاصيل» يبقى
- [ ] فاصل عمودي واضح بين الاسم والقيمة
- [ ] من `category_details` فقط
- [ ] مصفوفة فارغة → إخفاء القسم
