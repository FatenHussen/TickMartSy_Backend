تدفق السلة / الدفع **واجهتان**.  
**ما في أي ذكر لمدة التوصيل (`delivery_time`) داخل السلة.**

`delivery_time` يبقى على **صفحة المنتج** فقط (وبعد إنشاء الطلب على عناصر الطلب إن لزم).

## 1) القاعدة

| المكان | مدة التوصيل |
|--------|-------------|
| صفحة المنتج | ✅ اعرضوا `product.deliveryTime` إن وُجد |
| واجهة السلة 1 (منتجات + فاتورة + دفع + كوبون) | ❌ لا |
| واجهة السلة 2 (ملخص + تأكيد) | ❌ لا |
| `GET /api/user/cart` | ❌ الحقل غير موجود على عناصر السلة |

لا تضيفوا ويدجت «التسليم خلال…» ولا صف في الفاتورة لوقت التوصيل.

## 2) الواجهتان

### الواجهة 1 — السلة / الدفع

- قائمة المنتجات (كمية، ملاحظة، سعر)
- تفاصيل الفاتورة (مجموع، توصيل، خصم، …)
- اختيار طريقة الدفع
- الكوبون

### الواجهة 2 — الملخص

- ملخص الطلب فقط
- زر التأكيد

**لا** مدة توصيل في أي من الواجهتين.

---

## 3) أين يظهر `delivery_time`

```dart
// صفحة المنتج فقط
Text(product.deliveryTime ?? ''); // مثال: "3-5 أيام"
```

- مرة واحدة على المنتج — **ليس** per variant.
- في السلة: لا تقرأوا ولا تعرضوا الحقل حتى لو خزّنتم المنتج محلياً من التفاصيل.

---

## 4) الـ API

```http
GET /api/user/cart
```

عناصر السلة: `id`, `shop_product_variant_id`, `quantity`, `note`, `product.name`, …  
**بدون** `delivery_time`.

```http
GET /api/user/products/{id}
```

```json
{
  "delivery_time": "3-5 أيام"
}
```

بعد الطلب: `delivery_time` قد يظهر على عناصر الطلب — مو على شاشات السلة قبل التأكيد.

---

## 5) غلط vs صح

**غلط**

```dart
// في CartScreen / CheckoutSummary
Text(item.product?.deliveryTime ?? '—');
ListTile(title: Text('مدة التوصيل'), subtitle: Text(range));
```

**صح**

```dart
// Cart: منتجات + فاتورة + دفع + كوبون → ثم ملخص + تأكيد
// deliveryTime فقط في ProductDetailsScreen
```

## 6) Checklist

- [ ] واجهة 1: منتجات + فاتورة + دفع + كوبون — بلا مدة توصيل
- [ ] واجهة 2: ملخص + تأكيد — بلا مدة توصيل
- [ ] `deliveryTime` معروض على صفحة المنتج فقط
- [ ] لا تعتمدوا على `cart` لإرجاع `delivery_time`
- [ ] لا صف «التسليم» داخل ملخص الفاتورة في السلة
