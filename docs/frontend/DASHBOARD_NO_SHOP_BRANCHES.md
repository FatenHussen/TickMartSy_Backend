> **أرسلوا هذا الملف لفريق الداشبورد فقط.**  
> **آخر تحديث:** 20 أيلول 2026  
> Base: `/api/admin` + Admin token  
> **الباك جاهز بعد `git pull`**

> Flutter: [`FLUTTER_NO_SHOP_BRANCHES.md`](./FLUTTER_NO_SHOP_BRANCHES.md)

**ما في فروع.** كل بائع = **متجر واحد**.  
المنتج يُربَط بذلك المتجر تلقائياً.  
**لا** قسم «توفر الفروع». **لا** دروب داون «اختر الفرع». **لا** اسم فرع على فورم المنتج.

## 1) القاعدة

| قبل | بعد |
|-----|-----|
| بائع = عدة فروع | بائع = **متجر واحد** |
| الأدمن يختار فرع لكل متغيّر | الباك يربط كل المتغيّرات بالمتجر |
| `shop_variants` إلزامي لقناة المتجر | `shop_id` مرة واحدة — أو البائع |
| تحذير «غير مرتبط بفرع» | **لا تحذير** |

الموقع والتطبيق **ما رح يعرضوا** اسم المتجر على صفحة المنتج.

---

## 2) ماذا يُحذف من الواجهة

احذفوا بالكامل:

- قسم **«توفر الفروع»** / multi-select فروع على فورم المنتج
- دروب داون **«اختر الفرع»** وفلتر «بائع → قائمة فروع»
- أي تحذير **«غير مرتبط بفرع»** أو «فرع افتراضي» أو «فرعة المنصة»
- عرض `variants[].shops[].shop_name` كقائمة فروع
- تسمية Shop كـ **فرع** — صارت **متجر**

`shop_variants` **مو مطلوب** للحفظ. الباك يربط كل المتغيّرات بمتجر البائع.

---

## 3) إنشاء متجر

```http
POST /api/admin/shops
```

- `vendor_id` إلزامي
- إذا كان للبائع متجر مسبقاً → **422** `vendor_id`: «لكل بائع متجر واحد فقط»

لا حقل `is_default`. لا زر «إضافة فرع».

---

## 4) إنشاء / تعديل منتج

| القناة | ماذا ترسلون | ماذا لا ترسلون |
|--------|-------------|----------------|
| **للموقع** | `sale_channel=platform` | `vendor_id` · `shop_id` · `shop_variants` |
| **ربط بمتجر** | `sale_channel=shop` + `shop_id` **أو** البائع | قائمة فروع · `shop_variants` إلا إذا بدكم `cost_price` |

```text
# موقع
sale_channel=platform

# متجر — متجر واحد، بدون فروع
sale_channel=shop
shop_id=5
```

إذا أرسلتوا `shop_variants` القديمة (للتوافق): الباك يأخذ **أول** `shop_id` فقط ويتجاهل الباقي، ويربط **كل** المتغيّرات بذلك المتجر.

## 5) GET المنتج

```http
GET /api/admin/products/{id}
```

```json
{
  "sale_channel": "platform",
  "variants": [
    {
      "id": 91,
      "shops": [
        { "id": 5, "shop_id": 1, "shop_name": "تيكمول" }
      ]
    }
  ]
}
```

`variants[].shops` للسلة داخلياً (صف واحد). **لا** تبنوا منه UI فروع أو اسم فرع على الفورم.

---

## 6) غلط vs صح

**غلط**

```text
shop_variants[0][shop_id]=1
shop_variants[1][shop_id]=2
```

**صح — موقع**

```text
sale_channel=platform
```

**صح — متجر**

```text
sale_channel=shop
shop_id=5
```

## 7) Checklist

- [ ] احذفوا UI الفروع من فورم المنتج والمتجر
- [ ] متجر: بائع واحد ↔ متجر واحد — لا زر «إضافة فرع»
- [ ] منتج موقع: `sale_channel=platform` بدون `shop_variants`
- [ ] منتج متجر: `sale_channel=shop` + `shop_id` (أو البائع) بدون قائمة فروع
- [ ] لا توست «يجب اختيار فرع»
- [ ] لا تعرضوا `shop_name` على فورم المنتج
- [ ] النصوص: متجر / المتاجر — مو فرع / فروع
