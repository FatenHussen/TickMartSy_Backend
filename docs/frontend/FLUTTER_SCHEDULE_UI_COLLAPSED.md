## 1) القاعدة

| الحالة | ماذا يظهر |
|--------|-----------|
| افتراضي (سلة / تأكيد مخصصة) | `Text` + زر فقط |
| بعد `عرض تفاصيل الجدولة` | نفس الـ UI الحالي (مرة واحدة / دوري + تاريخ) |

لا تفتحوا الـ bottom sheet / التقويم / كروت التكرار تلقائياً.

---

## 2) الحالة الافتراضية (مطوي)

| العنصر | النص (عربي) |
|--------|-------------|
| النص | هل ترغب بجدولة موعد التسليم أو اختيار موعد تسليم دوري؟ |
| الزر | عرض تفاصيل الجدولة |

إنجليزي: *Want to schedule delivery or set a recurring delivery?* · زر *Show scheduling details*.

اقتراح UI: `Row` / `ListTile` تحت ملخص السلة — سطر واحد، مش كارد كبير.

الافتراضي: طلب مرة واحدة (`confirm_schedule: false`) طالما ما اختار جدولة بعد فتح التفاصيل.

---

## 3) بعد الضغط (مفتوح)

نفس الواجهة السابقة (اختيار مرة / جدولة + `start_date`).

---

## 4) الـ API — بدون تغيير

```http
POST /api/user/schedules/{id}/custom-basket/confirm
```

| الاختيار | Body |
|----------|------|
| جدولة | `{ "confirm_schedule": true, "start_date": "…" }` |
| مرة واحدة | `{ "confirm_schedule": false }` |
